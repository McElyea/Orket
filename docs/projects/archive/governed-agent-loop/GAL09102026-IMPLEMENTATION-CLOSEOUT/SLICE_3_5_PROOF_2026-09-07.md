## Outcome

Slices 3-5 now provide one separately packaged public-SDK-only reference
extension, exact Ollama target selection, live single-model and fixed
multi-model execution, bounded structured-output repair, and an issue-scoped
effect approval/recovery composition. Both live paths cross two separately
admitted iterations and reach host-verifier-backed terminal truth.

The effect proof uses a real external child, real framed host broker,
application approval services, the existing tool gate/filesystem adapter,
durable SQLite authority, real local filesystem observation/mutation, and an
explicit resumed second iteration. The deterministic provider remains a fixture
on that effect test; it is not part of the live-model claim.

## Claim Limits and Remaining Work

1. The live paths prove integration and truthful receipts, not comparative model
   quality or a multi-model quality advantage.
2. Exact model identities fail closed when unavailable. Silent or
   policy-approved model substitution is not exposed by this CLI slice.
3. The external package is local and separately built but is not hosted,
   committed, tagged, or published.
4. Python import scanning proves package conformance, not hostile-code OS
   containment.
5. The effect boundary is limited to exact issue-scoped `read_file` and
   approval-required `write_file`; it is not general filesystem authority.
6. There is no agent HTTP API, durable wake queue, scheduler, webhook ingress,
   continuously running supervisor, or supervisor-owned capacity lease.
7. Slice 6 remains blocked by architectural-truth B2 (`AT-EX-002`). Slice 7
   release actions and user acceptance remain open.
